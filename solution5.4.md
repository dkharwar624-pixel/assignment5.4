, I built a small design system using CSS variables and design tokens. I defined all variables in :root for global access, including primary color #0077b6, secondary color #00b4d8, background color #f4f6f8, and text color #333. I defined spacing tokens as small 8px, medium 16px, and large 32px, plus xlarge 48px, and font-size tokens as small 14px, medium 16px, large 22px, and xlarge 36px. I used these variables consistently in buttons with var(--primary-color), headings with font and color variables, and cards with spacing and background variables. I verified the power of variables by changing --primary-color in :root from blue to red, and observed that multiple elements including headings, buttons, card borders, and demo box borders all updated automatically without editing each selector. This approach makes the design system reusable, maintainable, and easy to theme.
